# Atomic Verification Setup

Break down groomed requirements into simple, granular, atomic pass/fail checks. Ensure no functional requirement or edge case is missed.

Output a checklist where every item is:
- Atomic (one verifiable behavior per item)
- Unambiguous
- Linked to the originating requirement
- Verifiable with a clear pass/fail result
