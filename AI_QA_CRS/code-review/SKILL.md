# Code Analysis & Review

Perform static analysis on PR code to catch potential logic bugs, edge-case vulnerabilities, security flaws, and performance bottlenecks before dynamic testing.

Report findings with:
- File and line references where possible
- Severity or risk classification
- Suggested fix or mitigation
