# Defect Analysis & Triage

Log, classify, and categorize all detected bugs by severity, component, and root cause to accelerate triage and dev resolution.

Maintain a defect log with:
- Defect ID and title
- Severity and priority
- Affected component
- Root cause
- Recommended next step
